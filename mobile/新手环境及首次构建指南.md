# Porten 移动端新手环境搭建及首次构建指南

> 适用对象：首次接手本仓库、需要在本机把 `mobile/`（Android 原生 + Flutter 混合工程）跑起来并打出 staging release 包的开发者。
> 本指南基于 2026-10 实际构建成功环境整理，所有版本均为已验证可用的组合，**请勿随意升级**。

## 二、国内镜像配置（首次安装必读）

1. **Flutter SDK**：clone 时通过镜像（当前环境用 `https://gh-proxy.com/https://github.com/flutter/flutter.git`），并设置环境变量：
   ```bash
   export PUB_HOSTED_URL=https://pub.flutter-io.cn
   export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
   ```
2. **Gradle 发行版**：`mobile/gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 已指向 `https://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-bin.zip`，无需手动下载。
3. **git push 到 GitHub**：直连可用则直连；若直连失败，注意 `gh-proxy.com` 等加速代理**不支持带 token 的写操作（push）**，push 请直连或换支持推送的镜像。

## 三、首次构建步骤

```bash
# 1. 拉取 Flutter 依赖（Flutter Module 内）
cd mobile/flutter/porten_flutter
flutter pub get

# 2. 构建原生混合工程（Android 侧会自动编译嵌入 Flutter AAR）
cd mobile
./gradlew assembleStagingRelease
```

- 产物路径：`mobile/app/build/outputs/apk/staging/release/app-staging-release.apk`
- release 构建仅保留 `arm64-v8a`（app/build.gradle.kts 的 `abiFilters`），体积约 21MB，避免全架构 56MB 包在手机浏览器下载截断。
- `versionCode` 每次**对外分发**必须递增（当前 9），否则覆盖安装会被安装器拒绝或静默失败。

## 四、构建成功经验与踩坑（重要）

1. **Flutter 引擎 so 精简**：release 的 `libapp.so`/引擎 so 可能带 165MB DWARF 调试信息，需手动 `llvm-strip` 精简后再打包，否则 APK 异常膨胀。
2. **改动后必须 clean 或确认 Dart 重建**：APK 总大小可能巧合相同，验证 Dart 产物是否重建看 `libapp.so` 字节数是否变化（`unzip -l` 查看）。分发前用 `aapt dump badging` 核对 versionCode、`apksigner verify` 验签、`unzip -t` 验完整性、`sha256sum` 留底。
3. **长构建放前台跑**：后台 gradle 任务可能被环境回收（daemon 被杀、无产物），构建/分析命令一律前台执行。
4. **flutter test 注意**：页面含无限 `AnimationController.repeat()` 时 `pumpAndSettle` 永不静止，测试需固定步进 `pump(duration)`。
5. **混合栈生命周期**：手动创建的 FlutterEngine（Add-to-App 缓存引擎）必须自行转发 Android 生命周期（appIsResumed/Inactive/Paused/Detached），否则引擎停留 detached，动画不调度、整个页面不可交互（r5 教训，见 `FlutterContainer.kt`）。
6. **Overlay 层自绘 UI 必须自带 Material 祖先**：否则 Flutter 会给 Text 强制画黄色双下划线（引擎调试标记），显式 TextStyle 也无效（r7 教训）。
7. **固定高度容器垂直居中**：先算 `(容器高 − 行盒高)/2` 再设 contentPadding，别赌 `isCollapsed`/`textAlignVertical`（r6~r7 五轮教训）。
8. **spaceBetween 容器的 children 必须是布局块而非单个元素**，否则元素间被均分撑散（r8 教训）。
9. **共享 provider 的时序状态（倒计时/loading）会跨页误伤**：Web 端倒计时是页面局部 state，Flutter 端共享后登录页发过的 60s 倒计时会误拦注册页发送（r9 教训）。

更多历史坑位见《瓶颈方案文档.md》（瓶颈 1~18）。
